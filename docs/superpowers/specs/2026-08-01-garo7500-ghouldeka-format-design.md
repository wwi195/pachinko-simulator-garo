# GARO7500 グールデカ形式 表示リニューアル 設計書

## 背景・目的

`C:\Users\ab_99\Desktop\garo7500-repo`（牙狼7500 疑似遊技シミュレーター）を元に、新規プロジェクト
`C:\Users\ab_99\pachinko-simulator-garo` を作成する。

- **中身（確率・状態遷移などのゲームロジック、演出画像）は変更しない**
- **見た目・表示フォーマット（統計パネル・操作ボタン・履歴欄など）を `pachinko-simulator-ghouldeka` と同じ形式に作り替える**
- 上記に伴い、GARO7500 固有だった「軍資金選択・機種選択・プレミアムプラン」の設定画面は撤廃し、グールデカと同様に画面を開いたら即プレイ開始する仕様に変更する

## プロジェクト構成

- 場所: `C:\Users\ab_99\pachinko-simulator-garo`（新規フォルダ、`garo7500-repo` は変更しない）
- Git: `git init` 済み。ローカルコミットのみ行う。GitHubへのpushは別途指示があるまで行わない
- ファイル構成: グールデカと同じ3分割
  - `index.html`（構造のみ）
  - `style.css`（グールデカのCSSをベースに、GARO7500の項目数に合わせて拡張）
  - `script.js`（GARO7500のロジック・テンプレートを移植）
  - `images/`（`garo7500-repo/images/` の10ファイルをそのままコピー）

## 削除する機能（軍資金・機種選択まわり）

グールデカには軍資金選択などの設定画面が存在しないため、GARO7500側の以下を削除し、固定値化する。

| 項目 | 現状 | 変更後 |
|---|---|---|
| 軍資金選択（¥10,000〜¥200,000） | Step1で選択 | 削除。所持金上限なしでプレイ開始（グールデカと同じ） |
| プレミアムプラン（¥10,000,000） | Step1の隠しボタン | 削除 |
| 交換レート（等価/3.57円返し） | Step2で選択 | 削除。**等価（4円/4円）に固定** |
| 店の条件（good/bad/worst） | Step3で選択 | 削除。**17回転/千円に固定**（`spk=17`、`SHOPS`テーブル参照をやめて定数化） |
| 回転数上限（`getSpinLimit`・閉店処理） | 所持金に応じた上限あり | 削除。上限なし、プレイヤーが「退店」を押すまで継続（グールデカと同じ） |
| セットアップ画面（`#setup`） | 起動時に表示 | 削除。ページを開いたら直接ゲーム画面が表示される |

`newState()` は引数なしで固定値（`reg:'par', spk:17, exRate:4.0`）を使って初期化する形に変更する。

## 画面構成

### タイトルバー
グールデカの `#title-bar` 形式で「牙狼7500 疑似遊技シミュレーター」を表示する固定バーを追加する。

### ヘッダー（統計表示）— グールデカの3行構成に合わせる

**1行目（回転数）**
- 今回転数（`S.cur`）／累計回転数（`S.ttl`）のみを表示する
- グールデカにある「モード」バッジ・「電サポ」欄は表示しない（GARO7500には持続的なモード切替がなく、当たり演出はすべてモーダル進行で自動完結するため、対応するデータが存在しない）

**2行目（持ち球／投資／収支）**
- 持ち球: `S.balls`（そのまま）
- 投資: `S.cashUsed`（そのまま、赤字表示）
- 収支: 新規にライブ計算して追加する。グールデカの計算式（`renderHeader()` の `shuushi = mochiInt * 4 - toushi`）と同じ方式で `Math.floor(S.balls) * S.exRate - S.cashUsed` を毎回更新して表示（プラスは緑、マイナスは赤）。500円単位への丸め（`floor500`）は退店時の精算画面のみで行い、ライブ表示では行わない（グールデカの挙動と一致させる）。現状の「現金残高」表示は所持金の概念がなくなるため廃止する

**3行目（大当たり回数・内訳）**
- グールデカの `hrow3` レイアウト（合計回数＋回転数レート表示＋内訳リスト）をベースに、GARO7500の内訳項目数に合わせて拡張する
- 合計: `S.hits.total`
- 内訳表示項目（グールデカの `hit-item` スタイルで表示）:
  - 図柄揃い合計（極限突入 / 非突入の内訳）
  - チャージ
  - 極限バトル成功（LT突入）／失敗
  - LT中: 7500初回／7500継続／1500継続ボーナス／1500終了
- 項目数が多いため、現行GARO7500にある「▶ 詳細を見る」の開閉トグルは維持する（グールデカにはないが、情報量の都合上必要と判断）。トグルボタンの見た目はグールデカのボタン系スタイルに合わせる
- 回転数レート表示は固定値「17回転/千円」を表示する（グールデカの `fee-block` に相当）

### 操作ボタン — グールデカの形式に合わせる

- **1回転**: グールデカの丸型STARTボタン（`.btn-start` の金色グラデーション）に差し替える
- **1万円分回す（一括）**: 「100回転」ボタンを廃止し、`pachinko-simulator-ghoul`（東京喰種版）で採用済みの「1万円分回す」方式に合わせる。グールデカの `.auto-spin-btns` 枠内にボタン1つを配置し、回転数は `spk×10`（固定レート17回転/千円のため170回転）を一括実行する。ボタン下に「約170回転分」のヒントテキスト（`.spin-cost-hint`）を表示する
- **退店**: グールデカの `.btn-taiten` スタイルに差し替える（機能は変更なし）

### 当たり演出（モーダル画面）

- 現行の全画面モーダルオーバーレイ方式（`showM`/`closeM`/`#ov`/`#mb`）は**そのまま維持する**（演出画像・演出の流れを変更しないため）
- モーダル内の「続ける」「▶ 次へ」等のボタンは、グールデカの `.btn-action` / `.btn-sub` スタイルに置き換え、配色・フォントをグールデカ系に統一する
- 演出画像（10ファイル）はそのまま `images/` フォルダから読み込む。画像プレースホルダー表示（`imgDiv` の仕組み）も維持する

### 履歴欄

- グールデカの `#log-area` / `#log-list` / `#log-title` のスタイルに合わせて再スタイルする
- 履歴の内容・ロジック（`addH`）は変更しない

### 精算（退店時の結果画面）

- 現行の精算モーダル（`showSettle`）はロジック・表示項目とも維持する。配色・ボタンのみグールデカ系スタイルに合わせる

## ロジック（変更なし）

以下はGARO7500の現行ロジックをそのまま移植する（定数値・確率・演出分岐は一切変更しない）:

- `C`（確率・獲得球数などの定数） — ただし `SHOPS`/`EX` テーブルは不要になるため削除し、`spk=17`, `exRate=4.0` を直接定数化する
- `oneSpin` / `doHit` の分岐ロジック
- 履歴・統計の集計ロジック
- 精算計算式（`floor500`, `rawExchY` など）
